# Play Console Listing Draft

## App name

경조사 인맥 관리

## Short description

경조사비, 인맥, 일정 알림, 통계를 한곳에서 관리하는 로컬 장부

## Full description

경조사 인맥 관리는 결혼식, 장례식, 돌잔치, 생일, 명절 인사처럼 놓치기 쉬운 관계의 기록을 정리하는 Android 장부 앱입니다.

지인별로 관계, 소속, 연락처, 메모를 저장하고 보낸 경조사비와 받은 금액을 날짜, 장소, 메모와 함께 기록할 수 있습니다. 다음에 챙길 일정은 알림으로 예약하고, 누적 지출/수입과 관계별 흐름은 통계 화면에서 확인합니다.

민감한 인맥과 금액 데이터는 기기 안에 저장하며, 필요한 경우 CSV 형태로 백업할 수 있습니다.
